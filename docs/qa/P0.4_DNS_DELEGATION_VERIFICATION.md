## A. Estado de la delegación DNS

**Resultado: DELEGACIÓN ROTA POR ERRATA EN UN REGISTRO NS.**

Consulta directa al servidor autoritativo de IONOS (`ns1017.ui-dns.biz` / 185.132.33.17):

```
notify.staflyapps.com. 3600 IN NS s3.lovable.cloud.     <-- INCORRECTO (falta la "n")
notify.staflyapps.com. 3600 IN NS ns4.lovable.cloud.    <-- correcto
```

Comprobaciones:

| Host | Resuelve | ¿Es servidor de nombres? |
|---|---|---|
| `ns3.lovable.cloud` | 162.159.8.208 | Sí (correcto, pero **no está publicado** en IONOS) |
| `ns4.lovable.cloud` | 173.245.58.40 | Sí |
| `s3.lovable.cloud` | 104.21.45.161 / 172.67.216.163 | **No** — es un host web, responde `REFUSED` a consultas DNS |

Resolución pública (Google DNS y Cloudflare DNS):

```
Status 2 (SERVFAIL)
EDE(23): rcode=REFUSED for notify.staflyapps.com/ns
EDE(22): No Reachable Authority at delegation notify.staflyapps.com
```

Esto **no es propagación pendiente**: el registro ya propagó, pero uno de los dos nombres apunta a un host que no atiende DNS, así que la mitad de las consultas fallan y la zona queda irresoluble para los resolvers estrictos.

### Corrección requerida en IONOS (dominio `staflyapps.com`)

| Acción | HOST | TYPE | VALUE | TTL |
|---|---|---|---|---|
| **Eliminar** | `notify` | NS | `s3.lovable.cloud` | — |
| **Crear** | `notify` | NS | `ns3.lovable.cloud` | 3600 |
| Mantener | `notify` | NS | `ns4.lovable.cloud` | 3600 |

No se debe crear SPF, DKIM ni MX en IONOS: pertenecen a la zona delegada y los publica Lovable.
