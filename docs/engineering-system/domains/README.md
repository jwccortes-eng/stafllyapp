## ¿Qué es un dominio?

Un **dominio** es una porción coherente de la realidad del negocio con
lenguaje, reglas, entidades y decisiones propias. No es lo mismo que:

| Concepto | Definición operativa |
|----------|---------------------|
| **Domain** | Área de negocio con lenguaje y reglas propias (p. ej. Payroll). |
| **Capability** | Función que un dominio ofrece (p. ej. "Consolidar base pay"). |
| **Entity** | Objeto de datos con identidad (p. ej. `pay_periods`). |
| **Experience** | Canal / superficie de entrega (p. ej. Worker Portal). |

Un dominio puede exponer capacidades en varias experiences.
