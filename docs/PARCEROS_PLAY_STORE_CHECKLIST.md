# Parceros — Google Play Console Checklist (Android)

Step-by-step checklist for Closed Testing and first Production release of
**Parceros** (`com.staflyapps.parceros`).

Companion to:
- `docs/MOBILE_RELEASE.md` — build flow
- `docs/PARCEROS_LAUNCH_ASSETS.md` — assets + copy
- `docs/PARCEROS_NATIVE_QA_MATRIX.md` — QA matrix
- `capacitor.parceros.release.ts` — release Capacitor config

> Stafly Core (`com.staflyapps.app`) is a **separate** Play Console app
> with its own checklist; do not mix the two.

---

## A. Play Console (one-time)

- [ ] Google Play Developer account active ($25 one-time fee).
- [ ] Identity verification complete (D-U-N-S or government ID, can take
      several days).
- [ ] All Apps → **Create app**
  - [ ] App name: `Parceros`
  - [ ] Default language: **Spanish (United States) — es-US**
  - [ ] App or game: **App**
  - [ ] Free or paid: **Free**
  - [ ] Declarations: confirm developer program policies + US export laws

## B. Capacitor / Android Studio setup (local)

- [ ] `cp capacitor.parceros.release.ts capacitor.config.ts`
- [ ] `npm install && npm run build`
- [ ] If `android-parceros/` does not exist: `npx cap add android`
      (the release config's `android.path` makes Capacitor target this
      folder instead of `android/`).
- [ ] `npx cap sync android`
- [ ] `npx cap open android`
- [ ] In Android Studio:
  - [ ] `applicationId = "com.staflyapps.parceros"` in
        `android-parceros/app/build.gradle`
  - [ ] `versionCode 1`, `versionName "1.0.0"`
  - [ ] `minSdkVersion 23`, `targetSdkVersion` = current Play requirement
        (34+ as of 2026)
  - [ ] Generate **upload keystore** (`*.jks`) and store it securely —
        losing it means you can never update the app again unless you
        enroll in Play App Signing key reset.
  - [ ] Build → Generate Signed Bundle → **Android App Bundle (.aab)**

## C. AndroidManifest.xml — v1

Located at `android-parceros/app/src/main/AndroidManifest.xml`.

Required:

```xml
<uses-permission android:name="android.permission.INTERNET" />

<application
  android:label="Parceros"
  android:usesCleartextTraffic="false"
  android:allowBackup="false"
  android:fullBackupContent="false"
  android:theme="@style/AppTheme">
  ...
</application>
```

**Do NOT add for v1** (kept out to simplify Play Review and minimize
runtime prompts):
- `ACCESS_FINE_LOCATION` / `ACCESS_COARSE_LOCATION`
- `POST_NOTIFICATIONS` (API 33+) — defer until push backend exists
- `CAMERA`
- `READ_MEDIA_IMAGES` / `READ_EXTERNAL_STORAGE` — use **Photo Picker** if
  avatar upload is added later (no permission required)
- `RECORD_AUDIO`

## D. Play Console — Main Store Listing

- [ ] App name (30): `Parceros — Trabajo cerca`
- [ ] Short description (80): see `docs/PARCEROS_LAUNCH_ASSETS.md`
- [ ] Full description (4000): see `docs/PARCEROS_LAUNCH_ASSETS.md`
- [ ] App icon: 512 × 512 PNG (generated by `@capacitor/assets`,
      `assets-source/parceros/icon.png` upscaled)
- [ ] Feature graphic: 1024 × 500 PNG/JPG
- [ ] Phone screenshots: at least 2, recommended 4–8, sizes 1080 × 1920
      to 3840 × 3840 — see `docs/PARCEROS_LAUNCH_ASSETS.md` §4
- [ ] 7-inch tablet screenshots: skip (declare phone-only)
- [ ] 10-inch tablet screenshots: skip
- [ ] Promo video (YouTube URL): optional, leave blank for v1

## E. Store Settings

- [ ] App category: **Business**
- [ ] Tags: `Work`, `Community`, `Productivity`
- [ ] Contact details:
  - [ ] Email: `info@staflyapps.com` (required, public)
  - [ ] Phone: optional, leave blank
  - [ ] Website: `https://staflyapps.com/parceros`
- [ ] External marketing: opt-out (default).

## F. Policy declarations

- [ ] **Privacy policy**: `https://staflyapps.com/privacy`
- [ ] **App access**: Restricted → "Some functionality is restricted" →
      provide demo phone + OTP for reviewer (mirror App Store reviewer
      note in `PARCEROS_APP_STORE_CHECKLIST.md` §I).
- [ ] **Ads**: No ads.
- [ ] **Content rating questionnaire**: complete → expected result
      **Everyone**.
- [ ] **Target audience**: 18 and over. Not designed for children.
- [ ] **News app**: No.
- [ ] **COVID-19 contact tracing**: No.
- [ ] **Data safety form** (mirror of Apple's nutrition label):
  - Collected: Name, Phone, Email, User ID, Messages.
  - Not collected: Location, Photos, Files, Contacts, Microphone,
    Calendar, Health, Financial info.
  - All data encrypted in transit. Users can request deletion via
    `info@staflyapps.com`.
- [ ] **Government apps**: No.
- [ ] **Financial features**: No.
- [ ] **Health features**: No.

## G. App content (compliance)

- [ ] No ads → "App contains ads? **No**"
- [ ] In-app purchases: **None** in v1.
- [ ] Sensitive permissions justification: **N/A** (no sensitive perms in
      v1 manifest).
- [ ] Data deletion request URL: `https://staflyapps.com/privacy`
      (Privacy Policy section explains email request flow).

## H. Closed Testing (recommended first release path)

- [ ] Testing → **Closed testing** → Create new track `parceros-closed`
- [ ] Add testers (email list or Google Group, max 100 for first round)
- [ ] Upload signed `.aab` produced in §B
- [ ] Release name: `1.0.0 (1)`
- [ ] Release notes:
      ```
      ES: Primera versión cerrada de Parceros. Comunidad de
          trabajadores, canales por zona y flash jobs.
      EN: First closed-testing release of Parceros. Worker
          community, area channels and flash jobs.
      ```
- [ ] Roll out → Closed Testing.
- [ ] Wait for review (~1–3 days first time).

## I. Production release (after Closed Testing PASS)

- [ ] All checklist items §A–G ✅
- [ ] `docs/PARCEROS_NATIVE_QA_MATRIX.md` PASS on real Pixel + emulator
- [ ] Production track → Create release → reuse `.aab`
- [ ] Staged rollout: **5% → 20% → 50% → 100%** over 2 weeks
- [ ] Monitor ANR/Crash rate in Play Console; halt rollout if either
      exceeds 1%.

## J. Common rejection guardrails

- ❌ Permissions in manifest that the app doesn't actually use → §C kept
      minimal.
- ❌ Missing Privacy Policy URL → set in §F.
- ❌ Data Safety form mismatch with actual collection → §F mirrors Apple.
- ❌ Restricted features (location/SMS/contacts/accessibility) without
      justification → v1 declares none.
- ❌ Repackaged or near-duplicate of another app (Stafly Core) → Parceros
      uses distinct branding, name, icon, screenshots, and copy. Same
      backend is allowed.
- ❌ `targetSdkVersion` older than current Play requirement.
